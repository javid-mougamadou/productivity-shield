Politique de confidentialité

Dernière mise à jour : 23 octobre 2026

productivity_shield est une extension Chrome open source qui bloque la navigation distrayante pendant des créneaux de productivité configurables. Cette page explique quelles données l'extension manipule et pourquoi.

Résumé

  • Aucune donnée n'est collectée, transmise ou vendue.
  • Aucun service d'analytics, de télémétrie ou de tracking tiers.
  • Aucune requête réseau sortante initiée par l'extension elle-même.
  • Toutes les données restent sur l'appareil de l'utilisateur.

Données stockées localement

L'extension utilise exclusivement les API de stockage locales de Chrome :

  • chrome.storage.sync — créneaux horaires configurés, listes de domaines (whitelist / blacklist / neutre) et profil actif (Normal / Zen / Focus). Synchronisé par Chrome entre les appareils de l'utilisateur connecté à son propre compte Google, jamais transmis à un serveur tiers.
  • chrome.storage.local — état de la pause en cours (minuteur de 10 minutes).

Ces données restent sous le contrôle de Chrome et de l'utilisateur. Les désinstaller supprime l'ensemble des données associées.

Permissions utilisées et pourquoi

  • storage — nécessaire pour enregistrer les créneaux, les listes de domaines, le profil et l'état de pause décrits ci-dessus.
  • tabs — nécessaire pour identifier l'onglet actif (afficher son domaine dans le popup, proposer les raccourcis whitelist/blacklist du site courant).
  • webNavigation — nécessaire pour détecter une navigation vers un nouveau domaine et décider, avant l'affichage de la page, si elle doit être bloquée selon le créneau et le profil actifs.
  • host_permissions (http://*/*, https://*/*) — nécessaire car l'extension doit pouvoir évaluer et, le cas échéant, bloquer la navigation sur n'importe quel site que l'utilisateur ajoute lui-même à sa blacklist — la liste des domaines concernés n'étant pas connue à l'avance, l'accès ne peut pas être restreint à un sous-ensemble de sites.

Dans tous les cas, ces permissions ne servent qu'à faire fonctionner l'extension localement dans le navigateur de l'utilisateur — aucune donnée de navigation n'est lue, enregistrée au-delà du strict nécessaire ci-dessus, ni envoyée où que ce soit.
